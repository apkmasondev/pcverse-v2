# PCVerse material revision v5

The motherboard albedo described below was superseded by [revision v6](PROVENANCE-v6.md), which restores the detailed v4 laminate and adds a dedicated SSD texture. This file records the original v5 generation.

`powder-coat-v5.png` was generated with the built-in ImageGen tool on 2026-09-20 and copied into this project. It is a raw neutral powder-coat colour texture; the model adds its own illumination, screws, ventilation slots, panel joints and lettering. The original generated file remains in the Codex generated-images directory.

Final prompt:

> Use case: product-mockup. Asset type: seamless base-color material texture for a realtime 3D PC power supply housing. Generate a square, perfectly flat orthographic macro sample of premium dark neutral graphite powder-coated steel, edge to edge. Extremely fine uniform powder micrograin with subtle stochastic density variation, clean new manufactured finish, restrained low contrast. Mid-dark charcoal grey (not pure black), neutral hue. Uniform diffuse cross-polarized illumination: NO directional shading, highlights, reflections, vignetting or lighting gradient. This is a raw albedo material tile, NOT an object or panel. NO screws, holes, vents, borders, logos, writing, seams, scratches, dust or decorative patterns. High material realism with fine scale; no coarse leather grain, no hammered metal, no carbon weave. Seamlessly tileable in both directions. Output 1024x1024.

`pcb-contact-ao-v5.png` is deterministic artwork generated by `scripts/atlas_surfaces.py` in motherboard coordinates. Contact occlusion includes only fixed board components so exploded parts do not leave baked shadows.

Normal maps and micro-roughness maps are generated by `scripts/atlas_details.py`. Their secondary UVs are generated at a consistent physical scale by `scripts/atlas_precision.py`, independently of text and routing artwork. Previous source textures are retained for provenance; the PSU and motherboard no longer use the old decorative panel/PCB images.
